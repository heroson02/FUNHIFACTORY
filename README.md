# FUNHIFACTORY - Project : 마지막 1초
iOS 채팅형 스토리 게임입니다. xcode를 사용해서 만든 네이티브 앱입니다.


![Image](https://github.com/user-attachments/assets/e0d8d638-818d-48ea-995b-c6a60a3ff5e7)

### 내가 기여한 부분

메인 게임 페이지 제작

- tableView를 사용해서 채팅방 구현
- collectionView를 사용해서 선택창 구현

게임 스토리 데이터 관리

- 스토리 구성요소들을 구조화하여 JSON으로 저장.
    - 스토리 스크립트와 사운드, 이벤트 모두 통합한 구조
- 스토리 데이터를 온라인으로 저장하고, 게임을 처음 시작할 때 다운받도록 함.

사운드 설정

- 게임 플레이 시 특정 상황마다 그에 맞는 bgm을 출력.
- 버튼 등의 UI와 상호작용 시 효과음을 출력.

설정 페이지 제작

- 배경음악, 효과음 관리 및 게임 속도 조정하는 기능 구현.

지도 페이지 제작

- 플레이어가 스토리에서 위치한 지역과 실제 사진을 불러오는 기능 구현.

### 사용 기술

- Swift
    - 게임의 구현 대부분을 Swift를 사용했습니다.
- JSON
    - 스토리 데이터를 JSON을 사용해서 저장했습니다.
